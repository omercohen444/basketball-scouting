# CI dependency set: `requirements.txt` minus the CrewAI tree.
#
# Why the split. The offline suite must pass with no credentials and no network,
# so it never runs a real agent — `agents/pipeline.py`'s StubBackend covers the
# whole chain, and `agents/crew.py` is imported lazily precisely so its absence
# degrades generation rather than breaking imports. CrewAI pulls ~130 packages
# (litellm, chromadb, onnxruntime) for code CI cannot exercise.
#
# Keeping this list explicit rather than clever: `tests/test_requirements.py`
# asserts the two files agree apart from the documented exclusion, so drift
# fails a test instead of silently reducing CI coverage.
